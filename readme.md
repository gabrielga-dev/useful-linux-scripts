# Useful Linux Scripts

A collection of useful Linux shell scripts for everyday tasks.

## Project Structure

Each folder in the repository contains a self-contained script with its own `README.md` documenting usage, prerequisites, and how it works.

```
useful-linux-scripts/
├── merge-pdfs/       # Merge multiple PDF files into one
│   ├── merge-pdfs.sh
│   └── README.md
└── readme.md
```

## How to Use

1. Navigate to the folder of the script you need.
2. Read its `README.md` for specific instructions.
3. Make the script executable (if not already): `chmod +x script.sh`
4. Run it following the documented usage.

## Contributing

To add a new script:

1. Create a new folder with a descriptive name.
2. Place your script inside it.
3. Add a `README.md` explaining usage, prerequisites, and how it works.
